Training and input regeneration use Python 3.10 with the pinned
\file{requirements.txt}: NumPy 1.26.4, SciPy 1.15.2, scikit-learn 1.7.2,
XGBoost 3.2.0, PyYAML 6.0.3 and matplotlib 3.10.7. The reference CLIP checkout
is \path{/users/robert.schoefbeck/CMS/tree_benchmark}; its Conda environment is
\code{tree-benchmark}. On CLIP use the conda-forge CPU XGBoost build, since the
PyPI Linux wheel requires newer glibc than the reference login environment.
No GPU is needed.

For a new training account or checkout, the complete environment-creation and
controlled refit recipe is in \file{docs/DORIAN_HANDOVER.md}. The datasets and
pickle archives are deliberately not in Git. Exact reproduction of the refit
starts from the hash-pinned terminal parent; rebuilding its entire L1 path can
produce differently serialized checkpoint bytes and requires a new explicit
source hash/run name. Existing named runs must not be resumed under changed
training code or stopping policies. The standalone \code{paper/} folder,
however, contains all generated text/tables and figures needed to compile this
PDF without datasets, model pickles or a Python training environment.

\textbf{Frozen coefficients and reference verification.}
\file{fpga_handoff/v3/manifest.json} hashes the candidate JSONs, hexadecimal C++
headers, feature contract, conservative training-box ranges and golden vectors.
Each candidate has both standardized and raw-input variants; choose one and
use its matching vectors and working-point threshold. The default JSON hash is
\begin{center}\footnotesize\ttfamily\CompactModelHash\end{center}
The corresponding immutable pickle is named by the checkpoint hash given in
the Compact training chain below, under \path{models/support_refit_scan_v1_selected/} on CLIP. The binary portable
JSON and headers suffice for firmware; Python pickles are not needed there.

The C++17 reference in \file{fpga_handoff/reference.cpp} passed all six v3
variants: 1,594 vector evaluations with exact leaf assignments and maximum
margin difference below $2.5\times10^{-14}$. The verifier
\file{scripts/verify_fpga_handoff.py} needs only Python's standard library and
a C++17 compiler. It checks bundle hashes before compiling/running the golden
vectors and preserves an existing frozen verification report. Fixed-point
verification remains a separate next step. v1 and v2 are retained historical
bundles; \file{fpga_handoff/CURRENT_MODEL.json} selects v3 Compact refit for new
implementation work.
